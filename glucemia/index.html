Glucómetro Accu-Chek Instant (Bluetooth)

Tu medidor usa el perfil estándar de glucosa Bluetooth, así que la página puede leer sus mediciones directamente.

  1. Abre esta página en Chrome o Edge (Android, Windows, Mac o ChromeOS). Safari en iPhone no permite Bluetooth web.
  2. Activa el Bluetooth del teléfono o computador.
  3. La primera vez, pon el medidor en modo de emparejamiento (según el manual del Accu‑Chek Instant: con el medidor apagado, mantén presionado el botón hasta que el símbolo de Bluetooth parpadee).
  4. Toca Sincronizar, elige el medidor en la lista y, si te lo pide, escribe el PIN de 6 dígitos impreso en la parte de atrás del medidor.
  5. Las siguientes veces basta con encender el medidor y tocar Sincronizar. Las mediciones repetidas no se duplican.

Si el medidor ya está emparejado con la app mySugr u otra app, puede que tengas que cerrarla para que esta página pueda conectarse.

Tus datos

Los datos se guardan solo en este navegador (no se envían a ningún servidor). Haz una copia de seguridad de vez en cuando, y úsala para pasar tus datos a otro dispositivo.

Importante

Esta herramienta sirve para llevar tu registro y conversarlo con tu equipo de salud. No reemplaza las indicaciones médicas. La HbA1c que se muestra es una estimación a partir de tus mediciones (fórmula GMI) y puede diferir del examen de laboratorio. Ante valores muy bajos o muy altos con síntomas, sigue tu plan de acción o busca atención médica.
